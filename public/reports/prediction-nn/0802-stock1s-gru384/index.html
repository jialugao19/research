Known data risks
risk_1
VWAP-validity filtering favors more active and liquid stocks/times; performance is conditional on this retained universe.
risk_2
fill_value=0.0 can conflate missingness with a genuine zero for fields without an explicit observation-quality mask.
risk_3
The 67-column projection was motivated by a precursor feature-health audit; that audit was not rerun on this exact 2021-2023 materialization.
risk_4
Observed schema hashes are consistent, but required_schema_hash is not pinned and integrity is size-based rather than content-checksum based.

Execution limitations
limitation_1
The simulator uses continuous AUM-normalized weights and assumes fill_ratio=1; it has no board-lot rounding or order-level fill ledger.
limitation_2
Commission, stamp duty, borrow fees and availability, and cash-equity T+1 constraints are not modeled.
limitation_3
The stock-level short leg is not directly executable for every name in cash equities.
limitation_4
Consequently this is a research portfolio simulation, not a deployment-ready execution backtest.

6.3. Interpretation Limits

limit_1
Only seed 7 is available for the current GRU384 formal result; seed variance is unknown.
limit_2
No 67-feature group ablation exists, so performance cannot yet be attributed to quote_state, quote_quality, or order_cancel_flow.
limit_3
Fold0 test covers 59 trading days in 2023Q1 only; this is insufficient evidence for Fold1 promotion.
limit_4
One-hour sequences and 10-minute labels overlap heavily, so row-level counts and t-statistics do not represent independent observations.
limit_5
Run metadata has checkpoint and eval-only metric-label inconsistencies; postprocess uses step 194640, but registry fields should be corrected before Fold1.
