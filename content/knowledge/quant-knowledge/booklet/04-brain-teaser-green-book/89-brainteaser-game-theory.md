# 89. Brain Teaser / Green Book：game theory 的策略、纳什均衡和博弈面试题应用

## 核心概念

game theory 是博弈论。

它研究的是：

```text
多个决策者相互影响时，每个人应该怎么选？
```

一个博弈通常包含：

```text
players   玩家
actions   每个玩家可选行动
payoffs   各种行动组合下的收益
information 信息结构
```

和普通优化不同，博弈论里你的最优选择取决于别人怎么选。

面试中最常见的问题是：

- 找占优策略。
- 找纳什均衡。
- 判断合作是否稳定。
- 求简单混合策略。
- 分析拍卖或报价策略。

## 收益矩阵

两人同时行动的博弈常用 payoff matrix 表示。

例子：

```text
              Player B
              L        R
Player A U  (2,2)   (0,3)
         D  (3,0)   (1,1)
```

每个格子 `(a, b)` 表示：

```text
Player A 的收益 = a
Player B 的收益 = b
```

如果 A 选 `U`，B 选 `L`，结果是：

```text
A 得 2，B 得 2
```

## 最佳反应

best response 是最佳反应。

给定对方策略，自己收益最高的行动就是最佳反应。

例子：

```python
payoff_a = {
    ("U", "L"): 2,
    ("U", "R"): 0,
    ("D", "L"): 3,
    ("D", "R"): 1,
}

def best_responses_a(action_b):
    actions_a = ["U", "D"]
    best = max(payoff_a[(a, action_b)] for a in actions_a)
    return [a for a in actions_a if payoff_a[(a, action_b)] == best]

print(best_responses_a("L"))
print(best_responses_a("R"))
```

结果：

```text
['D']
['D']
```

无论 B 选 `L` 还是 `R`，A 的最佳反应都是 `D`。

这说明 `D` 对 A 是占优策略。

## 占优策略

dominant strategy 是占优策略。

如果某个行动在对方任何选择下都不差，并且至少某些情况下更好，就可以说它占优。

在上面的例子中：

```text
如果 B 选 L：A 选 D 得 3，选 U 得 2
如果 B 选 R：A 选 D 得 1，选 U 得 0
```

所以：

```text
D strictly dominates U
```

严格占优策略是很强的概念。

如果每个玩家都有严格占优策略，预测结果通常很直接。

## 囚徒困境

prisoner's dilemma 是经典博弈。

两个玩家都可以：

```text
C = cooperate 合作
D = defect 背叛
```

收益矩阵：

```text
              B
              C        D
A C        (3,3)    (0,5)
  D        (5,0)    (1,1)
```

对 A 来说：

```text
如果 B 合作，A 背叛得 5，合作得 3
如果 B 背叛，A 背叛得 1，合作得 0
```

所以背叛是 A 的严格占优策略。

B 同理。

结果是：

```text
(D, D)
```

但双方都合作：

```text
(C, C) = (3,3)
```

对双方都比 `(D,D)=(1,1)` 更好。

这说明：

```text
个体理性不一定导致整体最优
```

## 纳什均衡

Nash equilibrium 是纳什均衡。

一个行动组合是纳什均衡，如果：

```text
给定别人不变，任何一个玩家都没有单方面改变策略来提高自己收益的动机。
```

囚徒困境中 `(D,D)` 是纳什均衡。

因为：

```text
给定 B 选 D，A 从 D 改成 C，收益从 1 降到 0
给定 A 选 D，B 从 D 改成 C，收益从 1 降到 0
```

所以没人愿意单方面偏离。

注意：

```text
纳什均衡不一定是总收益最大。
```

## 用代码找纯策略纳什均衡

给定小矩阵，可以枚举所有行动组合。

```python
actions_a = ["C", "D"]
actions_b = ["C", "D"]

payoff = {
    ("C", "C"): (3, 3),
    ("C", "D"): (0, 5),
    ("D", "C"): (5, 0),
    ("D", "D"): (1, 1),
}

def pure_nash_equilibria(actions_a, actions_b, payoff):
    equilibria = []

    for a in actions_a:
        for b in actions_b:
            current_a, current_b = payoff[(a, b)]

            best_a = max(payoff[(a2, b)][0] for a2 in actions_a)
            best_b = max(payoff[(a, b2)][1] for b2 in actions_b)

            if current_a == best_a and current_b == best_b:
                equilibria.append((a, b))

    return equilibria

print(pure_nash_equilibria(actions_a, actions_b, payoff))
```

结果：

```text
[('D', 'D')]
```

这段枚举适合小规模面试题。

大规模博弈需要更专门的方法。

## 协调博弈

coordination game 里，玩家希望选到同一种行动。

例子：

```text
              B
              A        B
Player 1 A  (2,2)    (0,0)
         B  (0,0)    (1,1)
```

纯策略纳什均衡有两个：

```text
(A, A)
(B, B)
```

代码：

```python
coord_payoff = {
    ("A", "A"): (2, 2),
    ("A", "B"): (0, 0),
    ("B", "A"): (0, 0),
    ("B", "B"): (1, 1),
}

print(pure_nash_equilibria(["A", "B"], ["A", "B"], coord_payoff))
```

结果：

```text
[('A', 'A'), ('B', 'B')]
```

这类博弈的难点不是有没有均衡，而是：

```text
玩家如何协调到同一个均衡？
```

在市场中，流动性迁移、交易所选择、标准协议采用，都有协调博弈的影子。

## 零和博弈

zero-sum game 是零和博弈。

一个玩家的收益等于另一个玩家的损失。

例如 A 的收益矩阵：

```text
              B
              L      R
A U           1     -1
  D          -1      1
```

B 的收益就是 A 的相反数。

这叫 matching pennies。

没有纯策略纳什均衡。

如果 A 固定选 `U`，B 会选 `R`。

如果 B 固定选 `R`，A 会选 `D`。

策略会互相追逐。

## 混合策略

mixed strategy 是随机化策略。

matching pennies 的均衡是：

```text
A 以 1/2 选 U，1/2 选 D
B 以 1/2 选 L，1/2 选 R
```

直觉：

如果 A 偏向某一边，B 就能利用。

只有随机到让对方无差异，才稳定。

## 求混合策略：让对方无差异

设 A 选 `U` 的概率是 `p`。

B 如果选 `L`，A 的收益是：

```text
U,L -> 1
D,L -> -1
E[A payoff | B=L] = p*1 + (1-p)*(-1) = 2p - 1
```

B 如果选 `R`，A 的收益是：

```text
U,R -> -1
D,R -> 1
E[A payoff | B=R] = p*(-1) + (1-p)*1 = 1 - 2p
```

B 想让 A 收益低。

在均衡里，A 需要让 B 对 `L` 和 `R` 无差异：

```text
2p - 1 = 1 - 2p
p = 1/2
```

对 B 也同理。

代码：

```python
def matching_pennies_expected_payoff(p_a_up, p_b_left):
    return (
        p_a_up * p_b_left * 1
        + p_a_up * (1 - p_b_left) * (-1)
        + (1 - p_a_up) * p_b_left * (-1)
        + (1 - p_a_up) * (1 - p_b_left) * 1
    )

print(matching_pennies_expected_payoff(0.5, 0.5))
```

结果：

```text
0.0
```

A 和 B 都随机一半时，A 的期望收益是 0。

## 反应函数

best response 也可以画成反应函数。

在很多博弈里：

```text
我的最优行动 = 对方行动的函数
```

简单价格竞争中：

```text
对方降价，我可能也降价
对方保持高价，我可能保持高价
```

纳什均衡是反应函数的交点：

```text
双方都在对对方做最佳反应
```

面试中不一定要求画图，但要能说出这个思路。

## 拍卖中的博弈

first-price auction 一价密封拍卖：

```text
每个人提交一个 sealed bid
出价最高者赢
赢家支付自己的出价
```

如果你的真实估值是 `v`，直接出价 `v` 通常不是最优。

因为赢了也没有剩余收益：

```text
profit = v - bid = 0
```

你会想 shading：

```text
bid < value
```

但出价越低，赢的概率越低。

所以这是一个权衡：

```text
更高 bid -> 更高获胜概率，但更低利润
更低 bid -> 更高利润率，但更低获胜概率
```

这就是博弈问题，因为其他人的出价策略会影响你的最优出价。

## 二价拍卖

second-price auction 二价拍卖：

```text
最高出价者赢
但支付第二高出价
```

在标准假设下，真实出价是占优策略。

直觉：

- 如果你赢了，支付价格由第二高出价决定，不是由你的出价决定。
- 出价高于真实价值，可能导致以超过价值的价格买入。
- 出价低于真实价值，可能错过本来有正收益的机会。

这说明机制设计可以改变策略激励。

## 交易中的博弈

市场中很多决策都有博弈成分：

- 做市商报价。
- 大单拆分。
- 交易所路由。
- 高频队列位置竞争。
- 拍卖开盘和收盘集合竞价。
- 其他策略对你的信号反应。

例如做市商报价：

```text
报价太宽 -> 成交少
报价太窄 -> 逆向选择和库存风险高
```

其他做市商的报价会影响你的最优报价。

如果所有人都缩窄 spread，利润可能被压缩。

如果市场压力大，大家撤流动性，spread 可能同时变宽。

## 重复博弈

一次性囚徒困境中，背叛是占优策略。

但如果博弈重复很多次，合作可能变得稳定。

原因：

```text
今天背叛会带来短期收益
但未来可能遭到惩罚
```

常见策略：

```text
tit-for-tat：第一轮合作，之后模仿对方上一轮行动
```

重复博弈里，未来收益折现因子越高，合作越容易维持。

面试中可以这样说：

```text
一次性博弈看当前收益，重复博弈还要看声誉、惩罚和未来互动。
```

## 常见错误

### 错误 1：把总收益最大当成纳什均衡

纳什均衡要求没有人想单方面偏离。

它不要求总收益最大。

囚徒困境就是典型反例。

### 错误 2：只看自己的收益，不看对方反应

博弈论的核心是相互反应。

你的策略改变会影响对方行为，对方行为又会影响你的收益。

### 错误 3：把占优策略和纳什均衡混淆

占优策略是单个玩家的行动性质。

纳什均衡是全体玩家的行动组合性质。

### 错误 4：忽略混合策略

有些博弈没有纯策略均衡，但有混合策略均衡。

matching pennies 就是例子。

### 错误 5：忽略信息结构

同时行动和顺序行动不同。

完全信息和不完全信息不同。

一次性博弈和重复博弈不同。

信息结构变了，均衡也可能变。

## 解题步骤

博弈论面试题可以按下面流程：

1. 明确玩家是谁。
2. 列出每个玩家的策略。
3. 写出收益矩阵或收益函数。
4. 看是否有占优策略。
5. 对每个对方行动找最佳反应。
6. 互为最佳反应的位置是纯策略纳什均衡。
7. 如果没有纯策略均衡，考虑混合策略，让对方无差异。
8. 检查是否是一次性还是重复博弈、同时还是顺序行动。

## 记忆要点

- 博弈论研究多方决策相互影响。
- 最佳反应是给定对方行动时自己的最优行动。
- 占优策略是不管对方怎么选都更好的策略。
- 纳什均衡是没有人想单方面偏离的策略组合。
- 纳什均衡不一定最大化总收益。
- 囚徒困境说明个体理性可能导致整体较差结果。
- 协调博弈可能有多个均衡。
- 零和博弈里一方收益是另一方损失。
- 混合策略通过随机化让对方无差异。
- 拍卖、做市、路由和流动性竞争都有博弈结构。
